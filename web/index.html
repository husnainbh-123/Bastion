    How Bastion works

    A chess engine answers one question over and over: which move is best here? Bastion does it in four parts, each built and tested on its own.

    Representing the board

    Positions are stored as bitboards: 64-bit integers with one bit per square, one for each piece type and colour. Questions like “which squares does this knight attack?” become a table lookup, and moves for a whole group of pieces come from a single bit shift. Rooks, bishops and queens use magic bitboards, a perfect-hashing trick that turns the pieces in a slider’s way into an index into a table of precomputed attacks.

    The move generator is verified with perft, which counts every position reachable to a fixed depth. Bastion matches the published counts for 27 test positions, over 800 million positions in total, including the awkward cases: castling through check, pinned pieces, en passant captures that expose the king, and promotions.

    Searching for the best move

    Bastion looks ahead with alpha-beta search, deepening one step at a time until its time runs out. A transposition table remembers positions it has already searched, and a quiescence search follows captures to the end so that it never judges a position in the middle of an exchange.

    The tree of possible games grows about thirty times wider with every half-move, so most of the engineering goes into deciding what not to search. Each technique in the table was measured by playing Bastion against a copy of itself with that technique switched off: 200 games each, at a fixed 20,000 positions per move so that only the quality of the search counts. The ± figures are 95% error margins.

    Judging a position

    When the search stops, an evaluation function scores the position with 564 weights covering material, piece placement, mobility, pawn structure, passed pawns, king safety and threats. Each weight has a middlegame and an endgame value, blended by how much material is left.

    The weights were learned rather than set by hand. Bastion played 11,978 games against itself, and a tuner adjusted every weight with gradient descent so that the evaluation predicts the results of 1,024,029 positions from those games as well as possible. In 140 test games the tuned version scored 80% against the original, a gain of 237 ± 51 Elo.

    Testing every change

    Changes are judged by games, not intuition. The project’s test scripts run sequential probability ratio tests, which keep playing until the result is statistically clear and then stop. Strength is reported as Elo, where a 100 point gap means the stronger side scores about 64%.

    On every push, continuous integration builds Bastion on Linux, Windows and macOS, runs the perft and unit tests, rebuilds with AddressSanitizer and UndefinedBehaviorSanitizer, and fuzzes the FEN and UCI parsers, the two places where untrusted input reaches the engine.

    Playing in your browser

    For this page the same C++ code is compiled to WebAssembly and runs in a Web Worker, so the page stays responsive while Bastion thinks. The legal moves, move notation and checkmate detection you see here all come from the engine itself, so the browser and the desktop engine share one set of chess rules.

    The weaker levels limit how far ahead Bastion looks and add noise to its judgement, which makes its mistakes look more human than random blunders would.

    How strong is it?

    Bastion's rating was estimated from games against reference engines with known ratings: the open-source engine Stash, and Stockfish held back to fixed skill levels. Across 160 games it performed at about 2867 on the CCRL blitz scale, with a 95% confidence interval of 2817 to 2916.

    That is well above the 2500 the project aimed for. Engine ratings come from games between engines, so they are not directly comparable with human ratings.

    The two kinds of reference disagree: Bastion performed at about 2985 against Stash and about 2801 against the Stockfish levels. Stockfish's levels search to a fixed depth, so unlike Stash and Bastion they lose little strength at a fast time control. A check points that way: here level 11 scored 75% against Stash 25, where the ratings predict 66%, so the Stockfish-based figure is probably the low one. The reference ratings come from the data Stockfish's developers used to calibrate its skill levels, and carry their own uncertainty of roughly 100 Elo.

    Games were played at 8 seconds plus 0.08 seconds per move for each side, with one thread and balanced openings. Full results are in the testing notes.
